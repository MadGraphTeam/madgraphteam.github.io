What's new in MadGraph7

A faster, smarter generation

MadGraph7 rebuilds the core of the generator around modern hardware and machine learning, while keeping the physics and the familiar workflow intact.

GPU
GPU-accelerated matrix elements
MadMatrix

Tree-level matrix elements evaluated on GPUs, giving large speed-ups for the most expensive part of event generation.

GPU
GPU-accelerated phase space
MadSpace

A fully parallel phase-space generator that runs on the same hardware as the matrix elements for end-to-end throughput.

ML
ML-accelerated event generation
MadNIS

Neural importance sampling that learns the integrand to reduce the cost of integration and unweighting.

Performance
Faster high-multiplicity processes
AmpliCol

Improved amplitude and colour handling for processes with many final-state particles.

Physics
Improved spin correlations
MadSpin

More accurate spin-correlated decays of intermediate resonances in MadSpin.

Web
Interactive web interface
MadBoard

A new browser interface that replaces the old static HTML run information with an interactive dashboard.

Core capabilities

A complete framework for collider phenomenology

MadGraph7 carries forward the full physics of the MadGraph5_aMC@NLO line — automated matrix elements and Monte Carlo simulation, from leading order for any user-defined Lagrangian to next-to-leading order for models that support it.

  • Automated matrix elements

    Tree-level and one-loop amplitudes for arbitrary processes, including loop-induced ones through MadLoop.

  • NLO QCD & electroweak

    Next-to-leading-order corrections in QCD and the electroweak sector for Standard Model processes.

  • Parton-shower matching

    MC@NLO matching to Pythia8 and Herwig with FxFx and MLM multi-jet merging, via standard Les Houches output.

  • Any model, including BSM

    Simulate any user-defined Lagrangian through the UFO model format, with models from FeynRules.

  • Spin-correlated decays

    Decays of intermediate resonances with full spin correlations using MadSpin.

  • Python 3 interface

    A scriptable Python 3 command interface for automated, reproducible runs.
