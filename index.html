About MadGraph

A complete framework for particle physics simulation

MadGraph is the leading open-source framework for automated generation of matrix elements and Monte Carlo event simulation, supporting tree-level and next-to-leading order (NLO) calculations matched to parton showers.

  • Automated NLO Calculations

    Full automation of next-to-leading order QCD corrections with FxFx multi-jet merging.

  • BSM Model Support

    Seamless integration with FeynRules for beyond-the-Standard-Model physics studies.

  • Parton Shower Matching

    Interfaces to Pythia, Herwig, and Sherpa for complete event simulation chains.
